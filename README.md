# Wenyue Zou — academic website

Live site: https://wenyue24.github.io/wenyuezou.ch/

A responsive, buildless website hosted on GitHub Pages.

## Frequent updates
- Biography and contact links: edit the about section in index.html.
- Education & Experience: add an article.timeline-item under education, using verified dates.
- News: add a dated paragraph at the top of news-list.
- Publications: duplicate an article.publication; update its title, authors, venue, links, figure and summary. Figures live in data1/img/; BibTeX in data1/bib/.
- Service: add teaching and verified student-supervision entries under Teaching & Student Supervision. There is no separate Students section.
- CV: replace data1/CV_Wenyue_Zou.pdf; all CV links use this file.
- Update the footer date when content changes.

Appearance lives in stylesheet.css; theme and navigation behavior live in site.js. Keep relative asset links for the /wenyuezou.ch/ project path. Content is readable without JavaScript.

## Publishing
Push to the existing main branch and check the GitHub Pages deployment.

## Design
Original implementation inspired by the academic layout at https://zdchan.github.io/. Existing Wenyue Zou assets and publication content are retained. No reference-site source or personal assets are copied.
